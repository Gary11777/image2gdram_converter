# Журнал изменений

Все значимые изменения в этом проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.1] - 2026-10-10

### Изменено

- В окне «Сохранить код» вместо подписи «Папка» показаны имена файлов, которые будут записаны.
- Кнопка «Выбор папки» заменена на «Сохранить».

### Исправлено

- Сохранение не меняет имя массива, параметры вкладки и текст в окне кода; в файлы записываются байты уже сгенерированного документа.

## [0.1.0] - 2026-10-07

### Добавлено

- Настольное приложение **Image2GDRAM Converter** для Windows (.NET 8, WPF): конвертация растров в GDRAM и генерация шрифтов для монохромных ЖКИ и OLED.
- Вкладка «Конвертер картинок»: загрузка BMP, PNG, JPEG и GIF (включая анимацию) через WIC; конвейер обработки (фон, поворот и отражение, масштабирование, порог и дизеринг); ручная правка с отменой и повтором; упаковка 1 bpp; интерактивная сетка предпросмотра и окно кода с подсветкой байта.
- Вкладка «Генератор шрифтов»: растеризация TrueType, лист символов PNG, импорт массивов из C и A51; таблица 16×16, редактор символа, диапазоны кодов и предпросмотр строки.
- Генерация вывода: C для Keil C51, C для STM32, A51 (отдельный модуль и фрагмент для `$INCLUDE`), BIN; кодировки CP1251 и UTF-8 без BOM.
- Встроенные пресеты дисплеев по приложению А ТЗ, пользовательские пресеты, `settings.json` и проекты `.iiu`.
- Скрипты `build.ps1` и `publish.ps1`, публикация single-file для `win-x64`; комплект документации в `docs/`; тестовые изображения и эталонные массивы в `testdata/`.

### Исправлено

- Имя массива по умолчанию обновляется при смене размера пресета.
- Отмена закрытия окна не сбрасывает несохранённые ручные правки.
- Сохранение сгенерированного кода не может перезаписать исходный файл изображения или шрифта на обеих вкладках.
- Повреждённый или отсутствующий словарь локализации не блокирует запуск приложения.
