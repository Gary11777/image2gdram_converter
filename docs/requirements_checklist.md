По мере работы в столбце «Статус» ставится `реализовано` (код есть) и `проверено` (тест зелёный или ручная проверка описана), с указанием теста или записи журнала. Тесты ядра — `Класс.Метод` из `tests/Image2Gdram.Core.Tests`; тесты декодера — из `tests/Image2Gdram.Imaging.Wic.Tests`.

Способы проверки:

| Код | Способ |
|---|---|
| UT | модульный тест ядра (`tests/Image2Gdram.Core.Tests`) |
| VT | тест сценария ViewModel (`tests/Image2Gdram.App.Tests`) |
| GT | золотой тест: сравнение сгенерированного текста с образцом |
| RT | побайтное сравнение с эталоном `testdata/reference/` |
| CC | дымовая компиляция `tools/compile-check.ps1` (если есть gcc/clang; на этой машине нет) |
| ПМИ | испытание по `docs/pmi.md` (ручное; часть — силами заказчика) |
| РП | ручная проверка при разработке (результат — в журнале плана) |
| ДОК | проверка наличия и полноты документа |

Модули сокращены: `Core.X` — пространство имён `Image2Gdram.Core.X`; `App` — WPF-приложение `src/image2gdram_converter`.
